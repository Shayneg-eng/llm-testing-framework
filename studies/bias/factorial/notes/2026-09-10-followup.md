# 2026-09-10 follow-up — belief vs. structure, and the Cell 2 anomaly

Same-day follow-up to `2026-09-10.md`, after the first full run of the 2x2 memory factorial (abortion_policy, Gemini-3.5-Flash-Lite, 5 replicates each cell).

## What the first factorial run showed

Memory dose-response ordering across the four cells, roughly: Cell 1 (both stateful) showed the most drift, consistent with a "Recursion Amplification" effect (~2.8 points vs. the Cell 4 null baseline) — the momentum/entrenchment pattern we expected from Ko & Geiping-style self-play. The surprise was **Cell 2** (attacker stateful / defender stateless): it produced *less* drift than even Cell 4 (both stateless, the null baseline with no memory anywhere). A fully-memoried attacker did worse against a memoryless opponent than an attacker with no memory at all.

## Mechanism check: read the Cell 2 transcripts

Read all 50 attacker critiques from Cell 2 (5 rounds x 2 trials x 5 replicates) looking specifically for the crude version of the hypothesis — the attacker quoting or referencing specific things the stateless defender said in an earlier round that it structurally cannot remember.

**Not found.** No verbatim callbacks to specific prior defender phrasing anywhere in the 50 critiques.

**Found instead:** persistent-opponent rhetorical framing in nearly every round-2+ critique — "my opponent retreats to...", "your persistent insistence on...", "continues to recycle the tired trope of...", "keeps cycling back to...". This language presupposes an interlocutor with an evolving, continuous position it is retreating from or clinging to. But the stateless defender has no such history — per the harness's design rule it re-defends the pristine original claim fresh every round, so it is never actually "retreating" or "insisting" on anything.

Working explanation: this is a **grounding failure** (classical dialogue-systems term, Clark & Brennan lineage) — a mismatch between what the attacker assumes the opponent has committed to and what the opponent actually has committed to (nothing, every round). The attacker's rhetoric is built for a target that doesn't exist in Cell 2, and that mismatch plausibly blunts attack effectiveness rather than sharpening it.

## New design: separating "has memory" from "believes the opponent has memory"

These two things are currently confounded. A stateful attacker has both conversational memory *and* a default (untested, never corrected) belief that its opponent is a continuous interlocutor. A stateless attacker has neither. Cell 2 vs. Cell 4 can't tell you which of those two factors is doing the work.

Proposed second 2x2, crossing attacker memory (stateful/stateless) with an explicit **informed** flag — a strictly factual, non-strategic instruction telling the attacker "your opponent will not retain memory of this conversation; each round they only see their original claim and your current critique" — all against the stateless defender:

| | uninformed (default) | informed |
|---|---|---|
| attacker stateful | Cell 2 (have it) | new |
| attacker stateless | Cell 4 (have it) | new |

Only two new conditions needed; two of four cells already exist.

- Stateful uninformed vs. stateful informed isolates the **belief effect** holding memory fixed: does correcting the false belief recover the lost drift?
- Stateless uninformed vs. stateless informed checks whether the belief does anything at all when the attacker has no memory to act on it with — a sanity check that the effect is about correcting a false belief, not just "mentioning memory" changing the prompt generically.
- Row/column main effects separate pure memory-structure effects from pure belief effects.

Risk to manage: the informing sentence must stay strictly factual/procedural. Any strategic coaching ("...so attack the original claim directly") would confound "correcting a belief" with "being told what to do."

## Literature check (dispatched to a research agent, 2026-09-10)

Verdict: **the specific manipulation looks novel.** No paper found isolates an attacker's belief about the *opponent's* memory state as a variable independent of the attacker's own memory, in an adversarial/persuasion LLM setting, with drift/concession as the outcome.

Closest related work, none of which overlaps directly:
- *Agent-to-Agent Theory of Mind: Testing Interlocutor Awareness among LLMs* (ACL/EMNLP 2025, arXiv 2506.22957) — spontaneous inference about interlocutor *identity*, not an assigned belief about memory state.
- *Belief Engine* (arXiv 2605.15343) — explicit belief-state manipulation, but of the agent's *own* stance, not its model of the other agent.
- *When collaboration fails* (Scientific Reports, s41598-026-42705-7) — adversarial persuasion dynamics in multi-agent debate; worth a direct read but nothing suggesting cross-agent memory-belief manipulation.
- *Effects of belief and memory on strategic negotiation* — pre-LLM, classical game-theoretic work; nearest conceptual analogue (belief about a counterpart's memory shapes strategy) but no LLMs, no belief-correction condition.
- *Does Good Memory Help You Win Games?* (arXiv 1505.02592) — longer memory underperforming a shorter-memory opponent, via payoff-tracking oscillation dynamics; a structural analogy for "memory can backfire," unrelated mechanism.

What's novel vs. extension: the underlying intuition (arguers tailor rhetoric to a model of what the opponent remembers/has committed to, and a wrong model causes talking-past) is old — classical dialogue/grounding theory, "goalpost-shifting" critiques in debate practice. The contribution is operationalizing this as a controlled, quantitative LLM experiment with a clean factorial that separates the belief from the underlying memory structure. Publishable framing: first controlled demonstration, not a new phenomenon.

Vocabulary to adopt: **interlocutor awareness** (existing term, re: identity) extended to *interlocutor state/persistence awareness*; **grounding failure** / **grounding correction** (the "informed" condition is a grounding correction) — both from classical dialogue-systems literature. No existing name for the manipulated variable itself; candidate coinage: **opponent-state belief** or **interlocutor persistence belief**.

## New direction: step back to the simpler question first — does memory matter at all?

Same day, after sketching the belief x memory 2x2 above. Decided to set that design aside for now (not dropped, just deprioritized) and lead with a coarser, more foundational comparison first: **Cell 1 (both stateful) vs. Cell 4 (both stateless)**.

- Cell 1: attacker and defender both retain full conversation history — matches the Ko & Geiping self-play setup.
- Cell 4: neither side retains anything — every round is an independent argument, attacker forgets its own prior critiques, defender re-defends the pristine original claim fresh each time. Pure "argument after argument," no continuity anywhere.

What this isolates: the combined, symmetric effect of memory on *both* sides at once — does a persistent debate escalate further than a series of independent one-off arguments. This is coarser than the belief/structure fork above: it doesn't say *which* side's memory is doing the work (attacker building pressure vs. defender eroding under sustained contact vs. both), only whether memory-on-both-sides matters at all relative to memory-on-neither-side. Cells 2 and 3 (and the belief-isolation design) are what would pull that apart later, if and when we come back to it.

Practically, this comparison is already sitting in the data: Cell 1 and Cell 4 both exist in the abortion_policy / Gemini-3.5-Flash-Lite / 5-replicate run. It's the same pair of numbers behind the "Recursion Amplification" metric already reported (~2.8 points, Cell 1 final-round mean minus Cell 4 final-round mean) — no new run needed to produce a first look at this, just re-cutting the existing chart/analysis to foreground Cell 1 vs. Cell 4 specifically instead of all four cells at once.

Open question, not yet decided: whether to just re-present the existing data this way, or gather more replicates / another topic / another model (e.g. add GPT-5.4-Nano back in) before treating "memory matters" as a finding worth leading with.
